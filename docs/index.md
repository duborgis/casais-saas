# casais-saas

A SaaS application designed for couples mediation and relationship management, featuring real-time communication and interactive tools.

## Overview

`casais-saas` provides a platform where couples can participate in mediated sessions, manage shared tasks, and communicate in a safe, structured environment.

### Key Features

- **Real-time Mediation**: Live sessions powered by WebSockets.
- **Secure Chat**: Instant messaging with state persistence.
- **Shared Management**: Tools for managing common relationship goals and tasks.
- **Privacy First**: Robust authentication and data isolation for each couple.

## Tech Stack

### Backend
- **Runtime**: Node.js
- **Framework**: Express
- **Real-time**: Socket.io
- **Database**: PostgreSQL
- **Auth**: JWT & Bcryptjs

### Frontend
- **Framework**: React 19 (Vite)
- **Language**: TypeScript
- **Styling**: TailwindCSS 4
- **Animations**: Framer Motion
